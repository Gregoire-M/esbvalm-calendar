# esbvalm-calendar
Create and publish an ICS file of ESBVA-LM games 🏀

The script builds the calendar from the upcoming home fixtures listed on the
ESBVA-LM ticketing calendar: https://billetterie.esbva-lm.com/fr/calendrier.
Date overrides and manually added matches can still be configured in
`overrides.yaml`.

You can subscribe to this calendar with this URL: https://symfonic.fr/esbva_lm_calendrier.ics
